How it works

Three simple paths — wake gently, remember what matters, or start a cozy timer.

Set a window

Pick when ringing should begin and end, how often to chime, and which days to repeat.

Capture a task

Type or write a title, add a due time and priority, then choose how you want to be reminded.

Start a template

Choose a category timer — CozyClock schedules the alert and lets you save your preferred pace.
